2. [11주차 과제답안 PDF](11주차_과제답안.pdf)를 함께 첨부합니다. LMS에 서술형 입력란이 있다면 [TXT 답안](11주차_서술형답안.txt)의 세 답안을 붙여넣으면 됩니다.

코드·입력·실행증빙은 보관 및 재현용이며 필수 LMS 첨부물은 아닙니다. JSON의 이름이나 내용을 바꾸지 마세요. 강의자료는 수업일 포함 7일 이내 제출을 요구하며, 실제 LMS 마감과 제출 완료 여부는 아직 확인하지 않았습니다.

## 실행 결과

교수자 원본 7개(실행기, 코드 2개, requirements, 입력 3개)를 바이트 그대로 복사하고 실제 실행했습니다. 교수자 저장소에 있던 출력 JSON은 복사하지 않고 새로 생성했습니다.

| 항목 | 비교 A: 1시간 | 비교 B: 같은 시각, 9일 |
|---|---:|---:|
| KS 통계량 | 0.175 | 0.225 |
| p_value | 0.5786 | 0.2657 |
| ks_significant | false | false |
| PSI | 0.1193 | 0.3324 |
| psi_band | 주의 | 경보 |
| alert_level | 주의 | 주의 |

`CH11_RUN_PASS`, `comparison_a_matches_ch2=true`를 확인했습니다. 강의자료 7쪽 표 11.6과 일치합니다. 여기서 2장 재현은 **교수자 제공 6월 28일 두 스냅샷**의 재현이며, 본인의 이전 2주차 과제에서 새로 수집했던 9월 데이터와는 별개입니다.

## 실행 범위와 재현

- Windows, Python 3.13.15, NumPy 2.5.4, pandas 2.3.3, SciPy 1.18.1로 실행했습니다. 교수자 requirements의 최소 버전을 충족합니다.
- 에어코리아 서울 40개 측정소의 제공 스냅샷 세 종을 재계산했습니다. 신규 API 호출, 실제 운영 경보 전송, 재학습은 하지 않았습니다.
- `11-0-collect-snapshot.py`는 원본 보관용이며 실행하지 않았습니다. 인증키는 필요하지 않습니다.
- 로그, 원본 SHA-256, 환경 버전, 독립 검산 결과는 `실행증빙`에 있습니다.
- 재검증은 아래처럼 실행합니다. 검증 도구는 임시 폴더에서 재실행해 제출 JSON 3개가 바이트까지 같은지 확인하므로 제출본을 덮어쓰지 않습니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r "실행증빙/requirements-lock.txt"
.\.venv\Scripts\python.exe "실행증빙/검증.py"
```

위 명령은 이 과제 폴더에서 실행합니다. 최초 산출물 생성 명령은 `python -u practice/chapter11/run_chapter11.py`입니다.

## 해석할 때 주의할 점

KS 비유의는 두 분포가 같다는 증명이 아닙니다. 이번 결과는 각 40건, 기준 분위수 5구간과 구간당 0.5 스무딩을 사용했으며, PSI 0.1/0.25는 이 실습에서 채택한 관행 임계입니다. 경보 조건은 AND이지만 주의 조건은 `KS 유의 OR PSI≥0.1`이라는 점을 구분해야 합니다.

데이터 결함과 성능 저하가 함께 확인된 경우의 답안은 강의자료 5쪽 표 11.5에 따른 조건부 설명입니다. 이번 PM10 비교에서 데이터 결함이나 성능 저하의 실제 원인을 확인했다는 뜻은 아닙니다.
