# 09주차 과제 제출

9주차 자료는 최상위 `9주차 과제물` 폴더에 모았다. 기존 7주차 제출물과 분리해 보관한다.

## LMS에 올릴 세 가지

1. [표 9.2 승격 게이트 최종본 PDF](09주차_표9.2_승격게이트_최종본.pdf): 설계표 7항목, 요구사항 근거, 양방향 실패 조건 및 3단계 실측 대조를 포함한다.
2. [ch9_experiment_report.json](practice/chapter9/data/output/ch9_experiment_report.json): 실습이 생성한 파일을 이름·내용 변경 없이 그대로 첨부한다.
3. [서술형 답안 PDF](09주차_서술형답안.pdf): 첫째 3문장, 둘째 2문장이다. LMS 본문 입력 방식이면 [TXT](09주차_서술형답안.txt)를 붙여 넣는다.

최종 제출 버튼을 누른 뒤 제출 완료 상태를 확인한다. **LMS 업로드는 아직 하지 않았다.** 기한은 수업일 포함 7일 이내이며 실제 수업일과 LMS 마감 시각은 확인되지 않았다. GitHub 업로드는 LMS 제출을 대신하지 않는다. 원천·모델 ZIP·실행 로그는 보관용이며 필수 제출 파일이 아니다.

## 결과와 구분

- 원본 스크립트 실제 실행: CH9_RUN_PASS, MLflow 3.14.0, scikit-learn 1.9.1, Python 3.13/Windows.
- 원본 판정: v1 MAE=1.0000 승격, v2 MAE=1.0455 절대 게이트 통과 후 상대 조건 실패로 반려, champion=1.
- 재훈련 메트릭·계수 일치, 별칭 로드 성공, 입력 9.0 → 예측 6.0 확인.
- 개인 설계는 MAE <=1.00 및 0.10 이상 개선이라는 **교육용 가정**이며 원본 스크립트의 1.05 게이트와 구분했다.
- 학생의 독립적인 실행 전 예측은 제공되지 않아 수행했다고 꾸미지 않았다. 설계 가정은 실제 훈련 전에 기록했지만 강의 예시 수치는 이미 읽은 상태였다.
- 입력은 제공된 고정 피처 스냅샷이며 외부 API 실시간 수집이 아니다. 훈련 6쌍의 MAE는 운영 성능을 입증하지 않는다.
