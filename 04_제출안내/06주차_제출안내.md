# 06주차 LMS 제출 안내

[6주차 과제 완성본](../6주차%20과제%20완성본/README.md)에 제출 자료와 실제 실행증빙을 모았다.

1. `6주차 과제 완성본/practice/chapter6/data/output/ch6_batch_run_report.json`을 수정 없이 첨부한다.
2. `6주차 과제 완성본/06주차_서술형답안.txt`의 답안 1~3을 LMS 본문에 입력한다. 답안 파일을 첨부하는 방식이면 `06주차_과제답안.pdf`를 함께 올린다.
3. 수업일 포함 7일 이내 제출하고 최종 제출 완료 상태를 확인한다.

GitHub 저장과 LMS 제출은 별개다. 현재 LMS 업로드·제출은 미수행이며 실제 수업일과 LMS 마감은 확인되지 않았다.
