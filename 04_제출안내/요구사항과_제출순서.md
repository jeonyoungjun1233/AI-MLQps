## 실행 결과의 성격

현재 준비된 JSON은 **교수자 저장소에 제공된 실제 응답 스냅샷을 현재 PC에서 재계산한 결과**다. 새 API 호출이나 가상 데이터 생성이 아니다. 원본 코드의 `extract_items`, `summarize_live`를 사용하고 `source`를 `snapshot`으로 정정했으며 원본 해시를 남겼다. `generated_at`은 재계산 시각이고 `data_time_min/max`는 원래 측정 시각이다.

강의 §7에는 인증키 없이 스냅샷으로 실행할 수 있다고 되어 있다. 그러나 실제 `code/1-1-public-api.py`는 키가 없으면 종료 코드 2로 끝나므로 별도 재계산 스크립트를 준비했다. LMS에 실시간 호출이나 `source=live` 조건이 추가로 있으면 본인 인증키로 실시간 실행 후 결과를 교체해야 한다. 시뮬레이터는 민원 데이터 구조여서 이 과제 대기질 JSON의 대체물로 쓰지 않는다.

## 처음부터 제출 완료까지

1. 폴더 최상단 `00_여기부터_시작.html`을 더블클릭한다.
2. 안내와 실행 결과를 읽고 이름·학번과 본인의 답변을 확인한다. 전영준 / 202373020을 반영했다. 실행 전 예측을 하지 않았으므로 1번에 미수행 사실과 사후 관찰을 적었다.
3. `답안 TXT` 또는 `답안 PDF`를 연다. 수정이 필요하면 TXT를 편집하고 PDF도 같은 내용으로 갱신한다. 이미 제출파일 폴더에 두 형식이 준비되어 있다.
4. LMS → 해당 과목 → **1주차 과제** 화면을 연다. 보내준 스크린샷의 강의자료 게시판과는 다르다.
5. 과제 제목·마감·확장자·개수 제한을 확인한다. 현재 자료에서는 답안의 TXT/PDF/ZIP 중 어느 형식이 필수인지 확정할 수 없다.
6. 본문 입력란이 있으면 세 답변을 붙여 넣고 `ch1_api_summary.json`을 첨부한다. 별도 답안 파일을 받으면 허용된 형식에 맞춰 준비된 TXT 또는 PDF를 첨부한다.
7. ZIP 제출 지시가 있으면 **JSON과 최종 답안만** 선택하여 Windows의 ZIP 압축 기능을 사용한다. 전체 강의저장소나 가상환경은 넣지 않는다.
8. 제출/저장 버튼을 누르고 최종 상태가 제출 완료인지 확인한다. 첨부한 파일을 다시 열어 확인하고 완료 화면을 보관한다.

현재는 제출 준비 단계이며, LMS에 업로드하지 않았다.

## 재실행

이 폴더를 PowerShell에서 열고:

```powershell
python .\03_1주차과제\실행_및_검증.py
```

표준 라이브러리만 사용한다. 실행하면 JSON과 실행증빙이 갱신된다. 최상단 HTML에 표시한 수치는 최초 검증 결과이므로 다른 스냅샷으로 바꿨다면 HTML도 다시 갱신해야 한다.

## 선택: 본인 인증키로 실시간 실행

본인 API 키가 있는 경우에만 실행한다. 키는 채팅·보고서·스크린샷에 넣지 않는다.

```powershell
Set-Location .\02_강의저장소\mlops_public\practice\chapter1
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r code\requirements.txt
# 로컬 터미널에서만 키를 설정한 뒤 실행
$env:DATA_GO_KR_API_KEY = '본인_인증키'
.\venv\Scripts\python.exe code\1-1-public-api.py --sido 서울 --rows 100
```

성공한 경우 `data/output/ch1_api_summary.json`을 개인 과제의 제출파일 폴더로 복사하고 답안의 실행 방식·건수·등식도 새 결과에 맞춘다. 실패하면 기존 저장소에 이미 있던 JSON을 새 결과라고 제출하지 말고 오류와 실행 시점을 기록한다.

## 강의자료 업데이트

현재 교수자 저장소의 원본 파일은 수정하지 않았다. 업데이트는 저장소 폴더에서 `git status`로 변경 여부를 확인한 후 진행한다. 변경이 없으면 `git pull --ff-only origin main`을 쓸 수 있다. 변경이 있을 때 스크린샷의 stash/pull/pop 절차를 적용하되, 새 파일은 기본 stash에 포함되지 않으며 충돌이 생기면 먼저 해결한다.
