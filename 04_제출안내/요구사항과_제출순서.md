# 01주차 과제 제출 안내

## 첨부할 파일

새 폴더 **`01주차 과제 제출`**에서 다음 두 파일을 첨부한다.

1. `ch1_api_summary.json`: API 키 없이 교수자 제공 실제 응답 스냅샷을 새로 계산한 결과.
2. `01주차 과제 제출.pdf`: 전영준 / 202373020, 세 문항 각각 세 문장.

본문 입력형이면 같은 폴더의 TXT를 붙여 넣고 JSON을 첨부한다. ZIP을 요구하는 경우에만 같은 폴더의 ZIP을 쓴다. ZIP은 PDF와 JSON으로 구성했다. 실행증빙은 참고용이다.

## 과제 조건과 현재 결과

| 항목 | 확인 |
|---|---|
| 실습 JSON | 새로 실행하여 생성, source=snapshot |
| 세 문항 답변 | 각 세 문장으로 작성 |
| 사전 예측과 실제 비교 | 사전 예측 미수행으로 이 활동은 미충족; 1번에 미작성 사실과 사후 관찰을 적음 |
| 응답 오류 지점·자동 검사 | items 누락·자료형 오류와 resultCode·배열 검사 설명 |
| 등식 | pm10_reported + pm10_missing = station_count, 40 + 0 = 40 검증 |
| 데이터 출처 | 교수자 저장소의 실제 응답 스냅샷; 가상 생성 아님 |
| 제출 기한 | 수업일 포함 7일 이내, 정확한 날짜·시각은 LMS에서 확인 |

1주차 PDF 9쪽에 인증키 없이 스냅샷으로 실행할 수 있다고 안내되어 있다. 원본 코드는 키가 없으면 종료하므로, 새 폴더의 실행증빙/재실행.py에서 교수자 원본의 추출·요약 함수를 호출했다. 이번 작업은 실시간 API 호출이 아니다.

## 제출 순서

1. PDF를 읽고 본인 답안 내용과 사전 예측 미수행 표시를 확인한다.
2. LMS 해당 과목의 1주차 과제 화면을 연다. 강의자료 게시판과는 다르다.
3. 정확한 마감과 허용 형식을 확인한다.
4. JSON과 PDF 또는 공지에서 정한 형태로 첨부한다.
5. 제출 버튼을 누르고 제출 완료 상태, 파일명, 첨부 내용을 확인한다.

GitHub 업로드만으로 LMS 제출이 되지 않는다. 현재 실제 LMS 제출은 하지 않았다.
