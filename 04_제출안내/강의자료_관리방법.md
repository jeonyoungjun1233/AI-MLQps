# 교수님 강의자료 관리 방법

## 현재 위치

사용 중인 `AI데이터개발MLQps` 폴더 안에 교수자 공개 저장소 전체를 클론했다.

```text
AI데이터개발MLQps/
├── 00_강의자료_목차.html       ← 전체 강의·실습 바로가기
├── 00_여기부터_시작.html       ← 1주차 제출 안내
├── 00_제출할파일_1주차/       ← 제출 JSON·답안 PDF
├── 01_강의원본/              ← 강의계획서·환경 설정 PDF
├── 02_강의저장소/
│   └── mlops_public/         ← 교수님 Git 저장소 전체
│       ├── lecture/          ← 주차별 강의
│       │   └── docs/         ← 상세 교재
│       ├── practice/         ← 주차별 실습 코드와 데이터
│       └── scripts/          ← 실습 환경 준비 도구
├── 03_1주차과제/             ← 내 작업과 실행증빙
└── 04_제출안내/              ← 제출·학습·자료 관리 안내
```

교수님 안내의 ‘내 문서’는 작업 위치 예시다. 이번에는 사용자가 현재 작업 중인 바탕화면의 과목 폴더에 정리했으며, Windows 문서 폴더로 이동하거나 중복 클론하지 않았다.

## 최신 자료 받기: 수정한 파일이 없는 경우

현재 과목 폴더에서 PowerShell을 열고 실행한다.

```powershell
git -C .\02_강의저장소\mlops_public status --short
git -C .\02_강의저장소\mlops_public pull --ff-only origin main
```

첫 명령의 출력이 없으면 수정한 파일이 없다. `Already up to date.`이면 최신 상태다. 이번 업데이트 확인 시 수정 파일은 없었으며 최신 상태였다.

## 교수님 실습 코드를 직접 수정한 경우

교수님이 안내한 stash → pull → pop은 **교수님 저장소 폴더 안에서** 실행한다. 아래 명령은 한 줄씩 결과를 확인하며 진행한다.

```powershell
Set-Location .\02_강의저장소\mlops_public
git status --short
git stash push -u -m "before-course-update"
git pull --ff-only origin main
git stash pop
git status --short
```

- `-u`는 아직 Git에 등록하지 않은 새 파일도 보관한다. Git이 무시하는 가상환경·인증키 파일 등은 포함하지 않는다.
- `No local changes to save`가 나오면 이번에 새 stash를 만들지 않은 것이다. 이 경우 마지막 `git stash pop`을 실행하지 않는다. 이전 stash가 잘못 복원될 수 있다.
- pull이 실패하거나 충돌 메시지가 나오면 다음 명령을 이어서 실행하지 말고 상태를 확인한다. `--ff-only`는 이력이 갈라졌을 때 자동 병합하지 않고 멈춘다.
- pop에서 충돌하면 임시 보관 내용은 남아 있다. 충돌을 해결한 후 필요에 따라 정리한다.
- 개인 과제는 바깥 `03_1주차과제`에 있으므로 교수님 저장소의 pull로 변경되지 않는다.

## 새 PC에서 처음 받는 경우

원하는 과목 폴더를 연 뒤, 대상 폴더가 아직 없을 때만 실행한다.

```powershell
git clone https://github.com/LeeSeogMin/mlops_public.git .\02_강의저장소\mlops_public
```

이미 `02_강의저장소/mlops_public`이 있으면 다시 클론하지 말고 위의 업데이트 방법을 사용한다.

## 두 GitHub 주소의 역할

| 주소 | 역할 |
|---|---|
| https://github.com/LeeSeogMin/mlops_public | 교수님 강의·실습 원본을 받는 곳 |
| https://github.com/jeonyoungjun1233/AI-MLQps | 내 과제·안내·실행증빙을 올리는 곳 |

개인 저장소는 교수자 복사본을 Git 추적에서 제외한다. 교수님 저장소 내부 파일명·배치를 그대로 유지하여 업데이트할 수 있게 했다.
