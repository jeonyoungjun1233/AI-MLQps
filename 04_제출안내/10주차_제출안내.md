# 10주차 LMS 제출 안내

[10주차 과제 폴더](../10주차%20MLQps%20%28202373020%20전영준%20과제%29/README.md)에 제출물과 실행증빙을 모았다.

1. `practice/chapter10/data/output/ch10_deploy_report.json`을 그대로 첨부한다.
2. `10주차_과제답안.pdf`를 첨부하거나 본문 입력 방식이면 `10주차_서술형답안.txt`를 입력한다.
3. 수업일 포함 7일 이내 제출하고 제출 완료 상태를 확인한다.

각 문항은 3문장이다. 실제 LMS 업로드·마감 시각 확인은 하지 않았다. GitHub 저장은 LMS 제출과 별개다.
