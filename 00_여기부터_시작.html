03 / 제출 전 꼭 읽을 두 가지

실시간 API 호출 결과가 아닙니다. 인증키가 없어 교수자 저장소의 실제 응답을 원본 요약 함수로 재계산했습니다. JSON에 source: snapshot으로 표시했습니다. 강의의 스냅샷 실행 안내를 근거로 준비했으며, LMS에서 실시간 실행을 따로 요구하면 결과 교체가 필요합니다.

실행 전 예측 활동은 미완료입니다. 본인이 아직 예측하지 않았다는 답변을 반영해 1번에 그 사실과 실행 후 관찰을 적었습니다. 사전 예측을 한 것으로 꾸미지 않았으므로 이 문항은 감점 가능성이 있습니다.

05 / 답안 미리보기

AI 데이터개발과 MLOps - 1주차 실습 과제
학번: 202373020
이름: 전영준

실행 방식
교수자 저장소에 제공된 에어코리아 실제 응답 스냅샷을 재계산했다.
인증키가 설정되어 있지 않아 이번 실행에서는 실시간 API를 호출하지 않았으며, JSON의 source는 snapshot이다.
강의의 스냅샷 실행 안내를 따르되, 원본 코드에 자동 스냅샷 처리가 없어 별도 실행 파일에서 원본 요약 함수를 호출했다.
원본 측정 시각: 2026-06-28 22:00 / 서울 측정소: 40개

1. 예측표에서 실제와 어긋난 항목 하나와 예측 이유
실행 전 예측표를 작성하지 않아 실제 결과와 어긋난 사전 예측 항목이나 그 이유를 제시할 수 없다.
실행 후 확인한 원본 응답에서 pm10Value는 숫자형이 아니라 "21"과 같은 문자열이므로, 집계 전에 숫자 변환과 결측 처리가 필요하다는 점을 확인했다.
이는 사전 예측과의 비교가 아닌 실행 후 관찰이며, 예측 후 실행하라는 활동 조건은 충족하지 못했다.

2. 코드가 가장 먼저 깨질 지점 하나와 자동 검사 방법
응답의 response.body.items가 누락되거나 배열이 아닌 경우, 측정소 목록을 읽는 단계에서 처리가 깨질 수 있다.
집계 전에 response.header.resultCode가 "00"인지와 items가 배열인지 자동 검사하고, 조건을 만족하지 않으면 오류를 기록한 뒤 집계를 중단한다.
HTTP 200만으로 정상 데이터라고 판단하지 않고 API 처리 상태와 응답 구조를 함께 확인한다.

3. pm10_reported, pm10_missing, station_count 사이의 등식
pm10_reported + pm10_missing = station_count가 성립해야 한다.
이번 스냅샷 재계산에서는 40 + 0 = 40으로 검증되었다.
각 측정소 레코드의 PM10 값은 보고값 또는 결측 중 하나로 분류되며, 이 시각의 결측 0건이 언제나 결측이 없음을 뜻하지는 않는다.
