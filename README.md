## 1주차 제출

`ch1_api_summary.json` + 세 문항 답변(문항마다 세 문장 이내). 수업일 포함 7일 이내 LMS에 제출한다. 답안 파일 형식과 정확한 마감 시각은 실제 LMS 과제 화면에서 확인한다. ZIP은 편의용이며 필수 형식이라는 근거는 없다.

**현재 결과는 제공된 실제 응답 스냅샷 재계산이다.** 실시간 API 호출로 표현하지 않았다. 사전 예측을 하지 않았다는 사용자 답변에 따라 1번 답안에 그 사실을 기재했으며, 해당 활동 조건은 미충족이다. 제출 전 내용을 읽고 이해한 뒤 확인해야 한다.

## 재현

```powershell
python .\03_1주차과제\실행_및_검증.py
```

교수자 저장소가 없는 새 PC에서는 먼저 다음 명령으로 원본을 받는다.

```powershell
git clone https://github.com/LeeSeogMin/mlops_public.git 02_강의저장소/mlops_public
git -C 02_강의저장소/mlops_public checkout 9b6618ca6efa5ca22f45301b824e62140519c204
```

Python 표준 라이브러리만으로 재계산한다. PDF 생성에 사용한 부가 도구는 실습 재실행에 필요하지 않다.

GitHub에는 개인 과제·답안·실행증빙·안내를 올린다. 제공 PDF 원본과 교수자 저장소 복사본은 로컬에 보관하고 Git 추적에서 제외한다. GitHub에서 받은 HTML의 원본 자료 링크는 해당 자료를 같은 폴더에 준비해야 열린다.
