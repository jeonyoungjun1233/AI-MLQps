## API 키 없이 재현

입력 스냅샷과 교수자 원본 코드를 제출 폴더의 실행증빙에 함께 보관했다. 저장소 루트에서 다음을 실행한다.

```powershell
python ".\01주차 과제 제출\실행증빙\재실행.py"
```

Python 표준 라이브러리만 사용하며 네트워크 요청이나 API 키가 필요하지 않다. `source=snapshot`으로 표시하고 건수 등식·평균·원본 해시를 검증한다. 측정 시각과 재실행 시각은 구분한다.

답안 PDF·TXT·ZIP 갱신 명령은 [먼저 읽기](<01주차 과제 제출/먼저 읽기.txt>)에 적었다. [강의자료 업데이트 방법](04_제출안내/강의자료_관리방법.md)도 참고한다.
