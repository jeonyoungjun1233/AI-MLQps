# 7주차 과제 완성본

실습 8.1을 실제 Feast 0.64.0 엔진으로 실행하여 원본 제출 JSON과 네 문항 답안을 준비했다. 각 답안은 **2·3·3·2문장**이다.

## LMS 제출 순서

1. [ch7_feature_report.json](practice/chapter7/data/output/ch7_feature_report.json)을 이름·내용 변경 없이 그대로 첨부한다.
2. [07주차_서술형답안.txt](07주차_서술형답안.txt)의 1~4번 답안을 LMS 본문에 입력한다. 답안 파일 첨부 방식이면 [07주차_과제답안.pdf](07주차_과제답안.pdf)를 함께 첨부한다. TXT와 PDF는 동일 답안이다.
3. 첨부·본문을 확인하고 최종 제출 버튼을 누른 뒤 제출 완료 상태를 확인한다.

**수업일 포함 7일 이내** 제출한다. 실제 수업일과 LMS 마감 시각은 미확인이다. 데이터의 7월 날짜와 실행일은 수업일을 뜻하지 않는다. **GitHub 업로드는 완료해도 LMS 제출을 대신하지 않으며, LMS 업로드는 아직 하지 않았다.** 전체 폴더나 실행증빙은 필수 제출 대상이 아니다.
