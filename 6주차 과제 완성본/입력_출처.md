# 입력 및 실행 출처

교수자 저장소의 chapter6 실행기, DAG와 사흘의 JSONL을 변경 없이 복사했다. 교수자 원본은 보존한다.

제공 저장소에는 DAG가 요구하는 `data/input/lawd_cd_seoul.csv`가 없으므로 강의 PDF 3쪽에 명시된 강남구=11680, 마포구=11440, 관악구=11620 세 행으로 보완했다. 서울 전체 매핑 원본을 확보했다는 뜻은 아니다. 이 실습 입력에 필요한 매핑이며 판교·성남시·김포는 매핑하지 않는다.

실행 환경은 GitHub Actions의 Ubuntu, Python 3.13, Airflow 3.3.0이다. 실제 결과와 로그는 실행 완료 후 보관한다. 외부 민원 API 호출이 아니라 고정 JSONL 배치 실습이다.

과제의 숫자 비교 기준은 PDF 3쪽의 ‘상세 원고 표 7.1 일별 정제 회계’이다. 저장소 `lecture/docs/chapter7.md`에서는 같은 숫자가 ‘2단계 실행 결과(실제)’에 있으며 표 7.1 자체는 스트리밍/배치 역할 비교로 표제가 다르다.

PDF의 CH7_RUN_PASS 표기와 달리 제공 chapter6 실행기의 실제 성공 표시는 CH6_RUN_PASS이다. 학생의 실행 전 예측은 제공되지 않았으므로 작성한 것으로 간주하지 않는다.
