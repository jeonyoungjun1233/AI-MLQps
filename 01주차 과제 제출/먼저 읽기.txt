01주차 과제 제출
202373020 전영준

[LMS에 첨부할 파일 2개]
1. ch1_api_summary.json : API 키 없이 제공 스냅샷을 다시 실행한 결과
2. 01주차 과제 제출.pdf : 세 문항 답안, 각 문항 세 문장

[LMS 화면에 따라 선택]
- 답안을 본문에 입력해야 하면 01주차 과제 제출.txt의 내용을 붙여 넣고 JSON을 첨부한다.
- ZIP을 요구하면 01주차 과제 제출.zip을 첨부한다. ZIP에는 JSON과 답안 PDF만 들어 있다.
- 실행증빙 폴더는 입력 스냅샷·원본 코드·재실행 코드·검증 기록을 보관한 참고 자료다. 별도 요구가 없다면 제출 첨부 대상은 위 두 파일이다.

[과제 조건 확인]
- 결과는 실제 응답 스냅샷을 재계산한 값이며 실시간 호출 결과가 아니다.
- 세 문항 모두 답안을 작성했다. 다만 1번의 사전 예측 활동은 하지 않았으므로 미작성 사실과 사후 관찰을 적었다. 예측을 수행한 것으로 꾸미지 않았다.
- 강의 PDF 9쪽에 인증키 없이 스냅샷으로 실행할 수 있다고 안내되어 있다.
- 원본 스크립트는 키가 없으면 종료하여, 별도 재실행 파일에서 원본 함수를 호출했다. API 인증키는 필요하지 않다.
- 수업일을 포함해 7일 이내 LMS에 제출한다. 수업 날짜를 받지 않았으므로 정확한 마감 날짜와 시각은 LMS에서 확인한다.
- GitHub 업로드와 LMS 제출은 별개다. 제출 버튼을 누르고 완료 상태와 첨부 파일을 확인해야 한다.

[다시 실행]
이 폴더에서 터미널을 열고:
python .\실행증빙\재실행.py

Python 표준 라이브러리만 사용하고 네트워크/API 키는 사용하지 않는다.
답안 PDF/TXT/ZIP도 다시 만들려면 이어서 아래 명령을 실행한다:
python .\실행증빙\답안_만들기.py
PDF 생성에는 reportlab과 Windows 맑은 고딕 글꼴이 필요하다.
