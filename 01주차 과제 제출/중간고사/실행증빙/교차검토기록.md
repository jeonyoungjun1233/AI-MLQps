# 최종 교차검토 기록

2026-10-21 / 학번 202373020 / 전영준

문제별 작성 담당과 다른 검토자가 원본 줄번호·수정 코드·실제 로그·답안 JSON을 읽고 대조했다. 부모 검토에서는 각 수정본을 import하지 않는 독립 계산으로 41개 필수 KEY를 비교했고, 최종 제출 문서와 실제 재실행 출력을 대조했다.

| 범위 | 재확인한 핵심 | 결과 |
|---|---|---|
| 문제1·2 | 같은 모집단에서 결측 평균 비교, 최고값 동점 이름순, 72분 도착의 마감 경계, 수정 전 지표 보존·해시 | 오류·누락 발견 없음 |
| 문제3·4 | A/B 커밋 산술, event_id/실제 Kafka 위치/시뮬레이션 위치 구분, 직전 파일 watermark·창 끝 경계, 14=13+1 | 오류·누락 발견 없음 |
| 문제5·6 | 17:10 이전 조건·중복 처음 유지·마감 밖6건, 보존식, 제공 확정 피처 유지, TTL72시간·미래 누출 진단·12개 샘플 | 오류·누락 발견 없음 |
| 종합 | 유실 우선 방지와 중복 제어, 스트리밍/배치 마감 범위, 공통 정의와 시점별 조회 구분 | 오류·누락 발견 없음 |

정확성을 높이기 위해 최종 답안에서 다음 두 표현을 다듬었다.

1. 문제5의 중복을 실제 네트워크 재전송으로 관측한 것처럼 표현하지 않도록 “정상적으로 제거한 재전송”을 “정상적으로 제거한 중복 기록”으로 바꿨다.
2. 종합 S-2에서 17:10 마감이 각 날짜의 접수 시각에 적용된다는 점을 명시했다.

그 후 제출 생성기를 다시 실행하지 않고 저장된 생성기 원문의 답 칸만 채웠다. 최종 `재실행.py`는 원본·수정본 총12개 실행 출력, 수정 코드 전문, 28개 답 칸, 필수 KEY41개와 원본35개 해시를 검증했다. 마크다운 파서에서도 표21개와 출력12개·코드6개를 확인했다.

이 기록은 실제 수행한 검증 범위의 결과이다. 교수자의 비공개 채점기 실행, 점수 확정, LMS 제출 완료는 확인하지 않았다.
