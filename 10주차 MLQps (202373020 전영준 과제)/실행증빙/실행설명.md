# 실행 범위 및 재현 안내

강의 PDF 전체 10쪽과 제공된 실행기·bootstrap·FastAPI 앱·pytest·Dockerfile을 읽고 원본 그대로 복사했다. 로컬 Windows에 Docker 실행기가 없어 GitHub Actions Ubuntu에서 실제 Docker 데몬으로 이미지 빌드·기동·HTTP 호출을 수행하도록 구성했다. `--skip-docker`나 컨테이너 모의 결과를 사용하지 않는다. 호스트는 개인 Windows가 아니라 해당 Linux runner의 호스트 프로세스를 뜻한다.

## 입력과 환경

입력은 교수자 제공 고정 피처 parquet이며 실제 민원 API를 호출한 것이 아니다. bootstrap은 9주차와 같은 훈련 절차로 독립 레지스트리를 재구성한다. 9주차의 기존 SQLite DB나 champion 별칭을 변경하지 않는다.

호스트 의존성은 원본 requirements에 원본 requirements-serve.txt를 constraint로 추가하여 FastAPI 0.139.0, uvicorn 0.50.2, MLflow 3.14.0, scikit-learn 1.9.0, pandas 2.3.3을 컨테이너와 맞췄다. 원본 두 requirements 파일과 Dockerfile은 수정하지 않았다. 두 환경의 전체 설치 목록은 host-requirements-lock.txt와 container-requirements-lock.txt에 각각 보관한다. 전이 의존성까지 모두 동일하다고 주장하지 않는다.

제공 저장소에는 실행기가 요구하는 `.github/workflows/ch10-model-api.yml`이 없었다. 개인 폴더와 저장소 루트에 새 워크플로를 작성했다. 루트 파일은 실제 GitHub Actions 실행용이고, 개인 폴더 사본은 원본 실행기의 REPO_ROOT 경로와 체크리스트 8번 및 단독 재현을 위한 정의다. 원래 교수자가 제공한 워크플로라고 주장하지 않는다.

## 증빙의 의미

- run.log: 원본 네 시나리오 실행 결과. GitHub실행.json: 실행 주소·소스 커밋·artifact 식별자.
- 이미지검증.json: 실제 빌드 이미지 ID·크기 및 호스트/컨테이너 app.py SHA-256 대조.
- image_app.py, image_export_info.json: 빌드 이미지에서 docker cp로 직접 추출한 파일.
- MLflow_실행원본.zip: 추적 DB·훈련 모델·내보낸 champion과 export_info를 보관한 증빙이며 LMS 필수 제출물이 아니다.
- 검증.py: 원본 보고서·체크리스트 8항목·shadow 값·이미지 파일을 대조하는 보관 자료 검증으로, HTTP나 Docker 실행을 대체하지 않는다.

교육용 모델·입력의 단일 스모크 결과만 검증한다. 모든 입력의 동등성, 예측 정확도, 부하 성능, 보안, 향후 모델 변경 뒤의 일관성까지 보증하지 않는다. 이미지 출처 메타데이터가 암호학적 서명을 대신하는 것은 아니다.

## 재실행

GitHub Actions의 **Week 10 model API Docker validation**에서 Run workflow를 실행하면 전체 실습을 다시 수행한다. 성공 후 week10-execution artifact를 받으면 된다. 실습 컨테이너는 원본 실행기의 finally에서 정리하며 외부에 상시 서비스를 배포하지 않는다.

Linux와 Docker가 준비된 별도 복사본에서도 아래 명령으로 실행할 수 있다. bootstrap은 자신의 DB·mlruns·model_export를 초기화하므로 보관용 제출 폴더에서 재실행하지 않는다.

```sh
python3.13 -m venv .venv
source .venv/bin/activate
pip install -r practice/chapter10/code/requirements.txt -c practice/chapter10/code/10-1-model-api/requirements-serve.txt
python practice/chapter10/run_chapter10.py
```

저장 결과의 독립 대조는 저장소 루트에서 아래처럼 실행한다.

```sh
python "10주차 MLQps (202373020 전영준 과제)/실행증빙/검증.py"
```

PDF 7쪽의 학생 실행 전 예측은 별도로 제공되지 않아 수행했다고 기록하지 않는다. 과제 세 답안은 실행 후 본인 JSON을 인용하여 작성한다. LMS 업로드·제출 완료는 별도 확인 대상이다.
